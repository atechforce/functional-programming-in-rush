# Functional Programming in Rust

Koleksi materi, contoh kode, dan latihan Pemrograman Fungsional (Functional Programming) menggunakan bahasa Rust.

## 📁 Struktur Materi

- **Root**
  - `main.rs`: Program pengantar Rust
  - `run_rust.ps1` / `run_rust.bat`: Skrip runner kompilasi & eksekusi cepat
  - `fibonacci_decoder.py`: Utilitas helper Python
- **Week 9: Pemrograman Fungsional di Rust**
  - `closures/`: Konsep closure, capture environment, closure sebagai parameter fungsi
  - `iterators/`: Dasar iterator, custom iterator, adapter & consumer
  - `map/`: Transformasi data dengan map, map struct, flat_map & chaining
  - `filter/`: Penyaringan data, filter struct, filter_map lanjutan
  - `fold/`: Akumulasi nilai dengan fold, fold untuk membangun koleksi, scan & reduce
  - `collect/`: Mengumpulkan iterator ke Vector, HashMap/HashSet, serta Result & Option
